# cti-platform 影片（HTML 骨架 + 音效 + 旁白腳本）

> 目前長度 **80 秒**（1:20），為的是讓旁白能完整講出重點。
> 早期版本是 60 秒，時間軸、字幕、音效都已換算到 80 秒版。

單檔、可編輯、可重現。畫面由秒數 `t` 決定，同一秒永遠長一樣；音效軌由 Python 標準庫合成，
固定種子，重新跑一次會得到位元相同的檔案。

- **開場**：2400 顆粒子聚成旋轉地球 → 爆散成紅點雨（**示意動畫，非實際統計**）
- **痛點／解法**：粒子堆成四座塔 → 被削平流入清單；每列各配一張示意圖
- **主畫風**：F1 圖表生長（深色 `#0f1418` / 藍灰 `#5d7fa3` / 暖橙 `#f1b25c`）；流程鏡頭用 M21 原理拆解
- **聲音**：無人聲，41 個對齊畫面節拍的音效點（無配樂）

風格來自 `code-animation-prompts` 技能（`%USERPROFILE%\.dsh\skills\code-animation-prompts`）。

## 粒子前段（示意）

- 粒子：2400 顆，固定種子；0–2.6 秒從散亂聚成旋轉球體，3.2 秒後爆散成紅點雨
- 痛點段：粒子重新聚成四座塔（高度 150–435 px 遞增），塔上方各一張示意圖
- 解法段：塔被「削平」，粒子流成弧線進入右側清單，每列一張對應示意圖
- **畫面上標明「示意動畫，非實際統計」**，並註明「紅點為示意，不代表任何國家的實際受害數」

為什麼是示意：專案裡**沒有國別攻擊資料**。實測 788 篇標題只有 18%（141 篇）能命中國名，
而且多數指的是「攻擊者來源」而非受害地。硬畫成「每國每天遭攻擊幾次」會變成捏造，
所以這一段只做氛圍，數字另外用真實的 788 篇／783 事件／35 個月補上。

> 早期版本用的是 Natural Earth 110m 點陣世界地圖（`analysis/filmstrip-60s.png` 舊版可見）。
> 改成粒子球後不再需要地理資料；`DATA.world` 仍留在 HTML 裡但前段已不使用，
> 要回到地圖版可從 git 或 `front-variants.html?v=A` 取回。

## 痛點 → 解法（出自 docs/tech-blueprint.md §3.1）

第一段先把問題講清楚，第二段逐條對上解法，讓評審知道「這東西解決了什麼」：

| 痛點 | 本專題的做法 | 證據 |
|---|---|---|
| 情資太多 | 自動抽出、去重、排序 | 788 篇 → 783 事件 → 288 個 CVE |
| 不知道先修哪一個 | 用 KEV（已遭利用）與 EPSS（利用機率）決定先後 | AUC 0.853 vs 純 CVSS 0.561 |
| 期限沒有依據 | 每一級附觸發路徑與期限 | 24 小時／7 天／30 天 |
| 在地情資被漏掉 | 語料納入台灣來源並標記本地通報 | 164 篇台灣來源 |

白皮書 §3.1 原本列七個痛點，影片只取前四個：第五到第七個（工具斷裂、決策無法解釋、
覆蓋缺口）偏內部設計，60 秒內講不完，放在簡報或問答更合適。

原本的「三個核心優勢（讀／排／說）」出自白皮書 §1 的「三個核心動作」，
改成痛點與解法後，這三點被吸收進上表的做法欄，不再單獨成段。

### 三個一定要說清楚的限制

1. **散點的「本系統名次」是重建的，不是平台內部 `risk_score`。**
   `patch_priority.csv` 只有 `priority` / `epss` / `cvss`，沒有連續分數欄位，
   所以排序鍵取 `(priority, EPSS, CVSS)`。這個排序與畫面上的 AUC 0.853 不是同一組計算。

2. **README.md 與 tech-blueprint.md 的數字有過時項。**
   `README.md` 寫「AUC 0.843／純 CVSS 0.546」、`tech-blueprint.md` 寫「741 件事件」，
   都與 `docs/evaluation.md`（0.853／0.561、783 件）不一致。evaluation.md 明言
   「對外引用的數字一律以本文件為準」，影片採用 evaluation.md。
   CVE 數 288 則與 blueprint 一致（273 只是有 CVSS 可算的子集）。

3. **世界地圖是示意。** 見上面「世界地圖」一節。

## 怎麼改

全部在 `index.html`：

- `SUBS`：字幕 `[開始秒, 結束秒, 文字]`

## 怎麼看

## MotionHarness 工程（可編輯）

`video/mh-cti60/` 是 Standard 專案，畫面來源就是這支 HTML 的移植版本：

| 檔案 | 說明 |
|---|---|
| `mh.json` | 1920×1080、30 fps、60 秒、音軌 `assets/sfx.wav`（0.4 秒淡出） |
| `src/scene.js` | 由 `video/index.html` 抽出繪製程式：`prepareFrame(time)` 直接呼叫原本的 `draw(t)` |
| `assets/sfx.wav` | 音效軌複本 |

在 `video/mh-cti60/` 下常用指令：

```
mh preview --times '[1,7,15,23,31,44,50,58]' --contact-sheet --output-dir .tmp/previews/p1
mh render .tmp/cti-60s-v1.mp4
mh preview --file .tmp/cti-60s-v1.mp4 --times '[0,30,59]' --contact-sheet --output-dir .tmp/check/v1
```

> **Node 版本限制**：`mh` 要求 Node ≥ 22.15，系統裝的是 22.11。
> 目前用 DSH 內建 Node 24，終端機要先跑：
>
> ```
> $env:PATH = "C:\Users\guo79\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin;" + $env:PATH
> ```
>
> 長期解法是把系統 Node 升到 22.15+。MotionHarness 預設開 telemetry，要關跑 `mh telemetry disable`。
