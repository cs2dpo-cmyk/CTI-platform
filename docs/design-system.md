# 科技風格設計規範（v1）

> 目的：把「科技風格」拆成**可以量測、可以勾選**的規格，避免做完之後只能說「感覺不夠科技」。
> 四個版本的可視稿在 docs/design/variant-a.png ～ variant-d.png。

---

## 0. 先確認需求（我的判讀）

| 你說的 | 我的理解 | 對設計的影響 |
|---|---|---|
| 「科技風格」 | 不是「電影裡的駭客畫面」，而是**精密感**：對齊、等寬數字、狀態色、克制的動效 | 拒絕大面積霓虹與裝飾性動畫 |
| 使用情境 | 課堂投影＋評審近距離看資料 | 先滿足**遠距可讀**，再談質感 |
| 內容性質 | 高密度表格、長數字、狀態標籤 | 密度優先於留白，等寬數字是必需 |
| 對象 | 部署商（工程師）與主管 | 兩層資訊：一眼看結論、往下看依據 |

**三個關鍵取捨**

1. **深色為主、淺色為輔**：投影時深底淺字更穩；列印與文件用淺色版。
2. **強調色只做「動作」與「當前狀態」**：不用來裝飾，否則 P1 的紅會失去意義。
3. **動效只回饋、不表演**：時長 ≤ 240ms，不做循環動畫（連線指示燈除外）。

**風險提示**：目前網站是 cyan＋粉紅漸層＋18px 圓角＋外發光，偏「產品行銷頁」。
要變「科技」，方向是：**降低圓角、降低發光、提高等寬字比例、收斂強調色**。

## 1. 配色

### 1.1 結構（12 色上限）

| 角色 | 數量 | 說明 |
|---|---|---|
| 背景 | 1 | 全站底色，不允許漸層 |
| 表面 | 2 | 卡片、內凹區 |
| 邊線 | 1 | 1px 髮絲線，全站同色 |
| 文字 | 3 | 主文、次要、極淡 |
| 狀態 | 4 | P1 紅、P2 琥珀、P3 青、成功綠 |
| 強調 | 1 | 主要行動與當前分頁 |

**判定**：任一畫面同時出現的色票 ≤ 12；超出即視為失控。

### 1.2 深色模式（預設）

| 角色 | 值 | 判定標準 |
|---|---|---|
| 背景 | #0B1220 | 明度 L* ≤ 15；禁止純黑 #000（投影會糊） |
| 表面 | #111A2B / #16223A | 與背景明度差 3～6 |
| 邊線 | #22304A | 與表面對比 1.5:1～2:1 |
| 主文 | #DBE6F5 | 對背景 ≥ 12:1 |
| 次要 | #7D8FAE | 對背景 ≥ 4.5:1 |
| 極淡 | #4B5C7A | 只用於 11px 標籤，不可用於正文 |

### 1.3 淺色模式（列印／文件）

| 角色 | 值 |
|---|---|
| 背景 | #F5F7FB |
| 表面 | #FFFFFF |
| 邊線 | #DFE6F0 |
| 主文 | #0F172A |
| 次要 | #5A6B85 |
| 強調 | #4F46E5（單一，不用漸層） |

### 1.4 強調色使用規則

- **面積上限 5%**（含按鈕、當前分頁、KPI 底線）
- **位置限定**：主要行動按鈕、當前分頁、關鍵 KPI 數字
- **禁止**：標題底色、表格斑馬紋、大面積漸層背景
- **判定**：畫面轉灰階後，強調色仍能指出「下一步做什麼」

### 1.5 狀態色（不可互相替代）

| 狀態 | 色 | 用途 |
|---|---|---|
| P1 / 危險 | #F87171 | 24 小時、KEV、刪除 |
| P2 / 警告 | #FBBF24 | 7 天、待處理 |
| P3 / 資訊 | #2DD4BF | 30 天、一般 |
| 成功 | #34D399 | 已連線、已完成 |

## 2. 字體

| 項目 | 規格 | 判定 |
|---|---|---|
| 中文 | Microsoft JhengHei / Noto Sans TC | 無襯線，不用楷體 |
| 英文 | Segoe UI / Inter | 與中文同字重 |
| 數字與代碼 | Cascadia Code / Consolas（等寬） | **表格數字、CVE、時間一律等寬** |
| 字重 | 400 / 600 / 700 | 不用 300（投影會消失） |
| 字級階 | 11 / 12 / 13 / 15 / 20 / 28 / 36 | 比例約 1.25，最多 7 級 |
| 行高 | 正文 1.55、標題 1.2、表格 1.4 | — |
| 字距 | 標題 -0.01em、全大寫標籤 +0.08em、等寬 +0.02em | — |

**判定**：任一頁面字級種類 ≤ 7；出現 10px 以下正文即不合格。

---

## 3. 間距

| 項目 | 值 |
|---|---|
| 基礎單位 | 4px |
| 階梯 | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 |
| 區塊內距 | 12～16px |
| 區塊間距 | 16～24px（約為內距 1.5 倍） |
| 表格列高 | 34～38px |
| 密度偏好 | 緊湊：一屏至少 8 列資料 |

**判定**：間距必須落在階梯上；出現 13px、17px 即不合格。

---

## 4. 圓角

| 元件 | 半徑 |
|---|---|
| 卡片 | 6px |
| 按鈕 / 輸入框 | 4px |
| 標籤 / Chip | 4px（狀態膠囊 999px） |
| 圖表容器 | 6px |

**判定**：全站圓角種類 ≤ 3 種。混用 2px 與 16px 會破壞一致性。

---

## 5. 陰影

| 項目 | 規格 |
|---|---|
| 有無 | 有，但只做層次，不做裝飾 |
| 方向 | 向下（y 正值） |
| 模糊 | 8～24px |
| 透明度 | ≤ 0.12 |
| 層數 | 卡片 1 層；hover 可加第 2 層 |
| 內陰影 | 只用於按壓（inset 0 1px 0 rgba(255,255,255,.04)） |
| 外發光 | **禁止**（B 變體強調按鈕除外，面積 ≤ 1%） |

**判定**：陰影 ≤ 2 層、模糊 ≤ 24px；出現「零位移大範圍外光」即不合格。

---

## 6. 動效

| 項目 | 規格 |
|---|---|
| 時長 | 120 / 180 / 240ms 三選一 |
| 緩動 | cubic-bezier(0.2, 0, 0, 1)（單一，全站共用） |
| 觸發 | hover、展開收合、資料更新、分頁切換 |
| 位移 | ≤ 8px |
| 透明度 | 0 → 1 |
| 循環動畫 | 只允許連線指示燈（2s 呼吸） |
| 無障礙 | 必須支援 prefers-reduced-motion（時長歸零） |

**判定**：動效 > 240ms 或使用彈跳曲線（overshoot）即不符合「克制」。

---

## 7. 網格

| 項目 | 規格 |
|---|---|
| 欄數 | 12 |
| 最大寬 | 1440px |
| gutter | 16px（緊湊）／24px（寬鬆） |
| 斷點 | 640 / 1024 / 1280 / 1536 |
| 對齊 | 文字左對齊；數字右對齊；表格首欄左對齊 |
| 模組化 | 卡片寬度 = 3 / 4 / 6 / 8 / 12 欄 |

**判定**：不得自訂其他斷點；卡片寬度不得出現「5 欄」這種破壞節奏的比例。

---

## 8. 資訊層級

| 層 | 用途 | 規格 |
|---|---|---|
| H1 | 頁標題 | 28px / 700 / 主文色 |
| H2 | 區塊標題 | 20px / 700 |
| H3 | 卡片標題 | 15px / 700 |
| Body | 表格與說明 | 13px / 400 / 行高 1.55 |
| Caption | 單位、時間、來源 | 11px / 400 / 次要色 |
| KPI | 關鍵數字 | 36px / 700 / **等寬** |

**閱讀動線**：標題（在哪）→ 數字（多少）→ 說明（為什麼）→ 操作（做什麼，固定右下）。

**判定**：每屏只能有一個最大字；同時兩個 36px 數字爭奪視線即不合格。

## 10. 建議：D 控制室

1. **投影可讀**：背景 L* 約 10，主文對比 12:1，後排也看得清。
2. **密度最大**：列高 34px，一屏 10 列以上，適合 288 筆清單。
3. **科技感來源正確**：來自精密（4px 圓角、髮絲線、等寬數字、單一琥珀），不是發光。
4. **與現有系統差距可控**：只需改 8 個 CSS 變數（見第 12 節），不用重寫版面。

**B 的定位**：適合 30 秒 Demo 的「哇」效果，但長時間閱讀疲勞、投影時發光會糊，建議只用在封面。

## 11. 驗收清單（可直接勾）

- [ ] 背景明度 L* ≤ 15，且不是純黑 #000
- [ ] 同屏色票 ≤ 12 種
- [ ] 強調色面積 ≤ 5%，只用於動作／當前狀態
- [ ] 四種狀態色沒有互相替代
- [ ] 字級種類 ≤ 7；最小字 11px
- [ ] 所有數字（表格、KPI、CVE、時間）為等寬
- [ ] 字重只用 400/600/700
- [ ] 間距全部落在 4 的倍數階梯
- [ ] 圓角種類 ≤ 3 種（4 / 6 / 999）
- [ ] 陰影 ≤ 2 層、模糊 ≤ 24px、透明度 ≤ 0.12
- [ ] 動效 ≤ 240ms，單一緩動，支援 reduced-motion
- [ ] 網格 12 欄，斷點 640/1024/1280/1536
- [ ] 每屏只有一個最大字
- [ ] 轉灰階後仍看得出「下一步做什麼」

## 12. 套用到現有專案

現有 static/css/styles.css 的 :root 只需改這 8 個值：

| 變數 | 現在 | 改成 |
|---|---|---|
| --bg | #060a11 | **#0b1220** |
| --panel | #0c1320 | **#111a2b** |
| --panel-raised | #101a2a | **#16223a** |
| --line | #1b2739 | **#22304a** |
| --cyan | #22d3ee | 保留（青綠作輔色） |
| --amber | #fbbf24 | **#f59e0b**（升為主強調） |
| --radius-lg | 18px | **6px** |
| --radius-md | 12px | **6px** |
| --radius-sm | 9px | **4px** |

另外三個行為調整：

- 移除 --shadow-panel 的外光成分，改為 1 層向下陰影
- 三組 --ease-* 收斂成一組 cubic-bezier(0.2, 0, 0, 1)
- 全站動效時長統一 120ms

改完後跑第 11 節的驗收清單，全部打勾才算符合「科技風格」。
